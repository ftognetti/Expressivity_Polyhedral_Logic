\section{Polyhedra}
As the title suggests, we are interested in compact polyhedra. Our approach is rooted in the interplay between the geometric and combinatorial facets of these objects,
an interplay that is captured most naturally by simplicial complexes.

Polyhedra are ``triangulable'' geometric objects, that is, subsets of some euclidean space that can be expressed 
as a union of simplices, much in the same way that any polygon can be expressed as a union of triangles.

It is fundamental to define what a (euclidean) simplex is and how to discard as much of the geometric information as possible 
to end up with a much easier combinatorial object, that essentially describes the structure of the 
polyhedron.
\subsection{Polyhedra and maps}
A simplex is the generalization of a triangle in arbitrary dimension. It is obtained by 
taking points in general position and taking their convex combinations, i.e. 
the minimal convex subset containing all of the points. 

This admits an explicit description:
\begin{definition}[Simplex]
    Fix a set of \textbf{vertices} $V\subseteq\R^n$ (for some $n\in \N$). For vertices $v_0,\dots,v_k\in V$ in general position (i.e., affinely independent), we say that
    \[\sigma=\set{\sum_{i=0}^k \alpha_i v_i\ |\ \alpha_i\in[0,1],\ \sum\alpha_i=1, v_i\in V}\]
    is a \textbf{face} or \textbf{simplex} on $v_1,\dots,v_k$.

    For a face $\sigma$ on $v_1,\dots,v_k$, a face whose support is a subset of these vertices is called a \textbf{subface} or \textbf{subsimplex}.

    If a face $\sigma$ has vertices $v_0,\dots,v_k$, we say that $\dim(\sigma)=k$.

    We call $\RelInt(\sigma)$, the \textbf{relative interior} of a face $\sigma$, the interior of the set in the smallest affine subspace of $\R^n$ containing it.
\end{definition}

We now define an intermediate step: We need a concept that resembles a polyyhedron, but whose data 
keeps track of the presence of all simplices.
\begin{definition}[Simplicial complex]
    A \textbf{simplicial complex} is a pair $K=(V,\Sigma)$ where $V\subseteq \R^n$ is a set ``of vertices'' and $\Sigma$ is a set of simplices such that
    \begin{itemize}
        \item if $\sigma\in \Sigma$ and $\sigma'$ is a subsimplex of $\sigma$, then $\sigma'\in\Sigma$;
        \item the relative interior of any two simplices is disjoint.
    \end{itemize}
    If $K=(V,\Sigma)$ is a simplicial complex, we say that $\dim(K)=\max_{\sigma\in \Sigma}(\dim(\sigma))$.
\end{definition}

Since simplicial complexes are ``polyhedra with extra structure'', we can forget this extra structure to define 
a polyhedron:

\begin{definition}[Polyhedron]\label{Polyhedron}
    Let $K=(V,\Sigma)$ be a simplicial complex. We call
    \[|K|=\bigcup_{\sigma\in\Sigma}\sigma=\bigsqcup_{\sigma\in\Sigma}\RelInt(\sigma)\]
    the \textbf{realization} of $K$, or the \textbf{polyhedron} associated to $K$.

    We say that $P\subseteq \R^n$ is a \textbf{polyhedron} if there exists a simplicial complex $K$ such that $P=|K|$.

    We say that $U\subseteq P$ is a \textbf{subpolyhedron} of $P$ if there exists a $K=(V,\Sigma)$ such that 
    $P=|K|=\bigsqcup_{\sigma\in\Sigma}\RelInt(\sigma)$ and there exists a subset $\Sigma'\subseteq \Sigma$ such that 
    $U=\bigsqcup_{\sigma\in\Sigma'}\RelInt(\sigma)$
\end{definition}

This leads to two notions of maps between polyhedra: one that preserves only the combinatorial structure of the simplicial complex, 
and a stronger one informed by the affine construction above, thus requiring a linearity condition 
on the simplices

\begin{definition}[Simplicial map, PL map]
    Let $K=(V,\Sigma),K'=(V',\Sigma')$ be two simplicial complexes.

    A map $f:|K|\to|K'|$ is called a \textbf{simplicial map} (or \textbf{polyhedral map}) if
    \begin{itemize}
        \item for any point $v\in V$, $f(v)$ is a point of $V'$, and
        \item for any simplex $\sigma\in\Sigma$, $f_{\to}(\sigma)$\footnote{Notation: if $f:X\to Y$ is a map, we denote $f_\to:\Pp(X)\to\Pp(Y)$ its image and $f^\gets:\Pp(Y)\to\Pp(X)$ its preimage} is a simplex of $\Sigma'$.
    \end{itemize}

    We further call $f$ \textbf{PL} (\textbf{piecewise linear}) if it is affine when restricted to any face.
\end{definition}

\begin{definition}[Triangulation]
    Let $P$ be a polyhedron in $\R^n$. A simplicial complex $K$ such that $|K|=P$ is called a \textbf{triangulation} of $P$.

    The set of triangulations of a given polyhedron is denoted $\Tr(P)$
\end{definition}

In particular, starting from a single simplicial complex, we can generate arbitrarily rich simplicial complexes that all realize the same polyhedron.
\begin{definition}[Barycentric subdivision]
    Recall that if 
    
    $\sigma=\set{\sum_{i=0}^k \alpha_i v_i\ |\ \alpha_i\in[0,1],\ \sum\alpha_i=1, v_i\in V}$, the point
    \[b_\sigma=\frac{1}{k+1}\sum_{i=0}^k v_i\]
    is called the \textbf{barycenter} of $\sigma$.

    Let $K=(V,\Sigma)$ be a simplicial complex. We call the \textbf{barycentric subdivision} of $K$ the simplicial complex $K^{(1)}$ having as vertices the set of barycenters of faces in $\Sigma$,
    \[V^{(1)}=\set{b_\sigma:\sigma\in\Sigma}\]
    and every simplex $\sigma$ is replaced by a set of simplices $\set{\sigma_j^{(1)}}_j$ 
    obtained by inductively replacing vertices with barycenters, in decreasing order of dimension:
    \[\sigma^{(1)}_{j}=\set{\alpha_1 v_1+\cdots+\widehat{\alpha_j v_i}+\alpha_j b_{\sigma}+\cdots+\alpha_k v_k\ |\ \alpha_i\in[0,1],\ \sum\alpha_i=1}\]

    We may iterate barycentric subdivision, and we denote $K^{(0)}=K$ and $K^{(n+1)}=(K^{(n)})^{(1)}$
\end{definition}

\subsection{Posets}

Forgetting the support in $\R^n$ gives a purely combinatorial description of a simplicial complex: what remains is essentially a downward-closed poset that describes how the simplices of the triangulation intersect and which simplices form the boundary of others.
\begin{definition}[Face poset]
    Let $K=(V,\Sigma)$ be a simplicial complex. We call $[K]=(\Sigma,\subseteq)$ the \textbf{face poset} of $K$.
\end{definition}

The connection is tight: the face poset $[K]$ already contains everything we need to recover the structure of $K$ up to PL-homeomorphism.
\begin{lemma}
    Let $K,K'$ be two simplicial complexes with $[K]\simeq [K']$. Then there exists a PL-homeomorphism $K\simeq K'$.
\end{lemma}
\begin{proof}
    See \cite[Lemma 2.18]{PLTopology}.
\end{proof}

This allows us to give adefinition of the resulting combinatorial object:
\begin{definition}[ASC]
    An \textbf{abstract simplicial complex}, or \textbf{ASC}, is a pair $K=(V,\Sigma)$ where $V$ is a set and $\Sigma\subseteq \Pp(V)$ is a collection of subsets of $V$ closed under taking subsets.

    Given a simplicial complex $K$, associating to each face the set of its vertices yields an ASC $\overline{K}$.
\end{definition}

Abstract simplicial complexes are the combinatorial counterpart of simplicial complexes: If a polyhedron results from a simplicial complex by forgetting the combinatorial strucure, an ASC results from a simplicial complex by forgetting the geometric structure.

In the same way that every simplicial complex arises from an essentially unique polyhedron, every ASC arises this way from an essentially unique simplicial complex.
\begin{lemma}
    Let $K$ be an ASC. Then there exists a simplicial complex $K'$ such that $\overline{K'}=K$.
\end{lemma}
\begin{proof}
    Realize every $d$-simplex as the standard simplex of the appropriate dimension in $\R^{d+1}$, and glue them together according to their intersections; see \cite{PLTopology} for a complete account.
\end{proof}
Together, these two lemmas give a correspondence
\[\dfrac{\set{\textbf{Simplicial Complexes}}}{\text{PL-homeomorphism}}\leftrightarrow\set{\textbf{ASCs}}\]
since to each ASC we may associate a simplicial complex, and we will show that any two simplicial complexes associated to the same ASC are PL-homeomorphic.

We also want a way to define an (abstract) simplicial complex from any poset:

\begin{definition}[Nerve]
    Let $(P,\leq)$ be a poset. We call $\Nn(P)$, the \textbf{nerve} of $P$, the abstract simplicial complex whose vertices are the elements of $P$ and whose simplices are the flags $p_1<\cdots<p_k$ of ordered elements of $P$.
\end{definition}

We will freely use the fact that nerves and barycentric subdivision are essentially the same operation.
\begin{theorem}
    If $K=(V,\Sigma)$ is a simplicial complex, then
    \[\Nn(\Sigma)=\overline{K^{(1)}}.\]
\end{theorem}
\begin{proof}
    See \cite{PLTopology}.
\end{proof}
Intuitively, every point of $\Nn(\Sigma)$ is a chain, that corresponds uniquely to a simplex (the maximal simplex of the chain).

Inserting a point for every simplex is -- up to PL-homeomorphism -- the same process as adding the barycenter of that simplex.
Then the simplices connecting everything follow from the chain inclusion.

\subsection{Subdivision theorems}
We are interested in polyhedra as semantics for modal logic, and so our choice of morphisms differs slightly from the classical framework. 

The purpose of this subsection is to provide a foundation of lemmas that we may use to refine our triangulations without losing information in our evaluations, thus in our semantics.

Recall first that, given (binary) Kripke frames $(W,R)$ and $(W',R')$, a function $f:W\to W'$ is called a \textbf{p-morphism} if and only if it satisfies the conditions
\begin{enumerate}
    \item $w R w'$ implies $f(w) R f(w')$;
    \item $f(v) R w'$ implies that there exists $w\in W$ such that $v R w$ and $f(w)=w'$.
\end{enumerate}

If $R=\leq$ is a partial order, these two conditions become equivalent to
\[\forall w\in W.\ \uparrow f(w)=f(\uparrow w),\]
where $\uparrow w=\set{v\in W: w\leq v}$. We refer to this property as \textbf{upward-closure}.

The proofs of all the following lemmas can be found in \cite{Dekker}.
\begin{lemma}[\cite{Dekker}\textbf{2.78} : Subdivisions are p-morphic] \label{subpm}
    The map $K^{(1)}\twoheadrightarrow K$ sending each face of $\Sigma^{(1)}$ to the (unique) face of $\Sigma$ containing it is a p-morphism.
\end{lemma}

We will also need the fact that we can avoid talking about arbitrary subdivisions and only care about the nerves, i.e. barycentric subdivisions.
\begin{lemma}[\cite{Dekker}\textbf{2.56}: Nerves are dense] \label{nervesdense}
    Let $K$ be a simplicial complex and $L$ a subdivision of $K$.

    Then there exists $n\in \N$ such that $K^{(n)}$ is (isomorphic to) a subdivision of $L$.
\end{lemma}
A barycentric subdivision is a refinement of the triangulation, and taking ``enough'' nerves corresponds to taking ``arbitrarily fine triangulations'', thus refining all possible (finite) triangulations of a given polyhedron. 

To state it we need to define (posetal) up-reductions:
\begin{definition}[posetal up-reduction]
    Let $P,Q$ be posets, we call a \textbf{posetal up-reduction} $f:P\upred Q$ a surjective partial map 
    defined on an upward-closed subset $U$ of $P$ such that $f_{|U}$ is a p-morphism.
\end{definition}

Lastly we want to know what happens to p-morphisms under subdivision:
\begin{lemma}[\cite{Dekker}\textbf{4.1}: Subdividing p-morphisms] \label{extension}
    Let $K,K'$ be simplicial complexes and $f:[K]\upred [K']$ a posetal up-reduction.

    Let $L'$ be a subdivision of $K'$. Then there exists a subdivision $L$ of $K$ and a posetal up-reduction $[L]\upred [L']$ such that

    \[\begin{tikzcd}[ampersand replacement=\&]
	{[K]} \& {[K']} \\
	{[L]} \& {[L']}
	\arrow["\circ"{description, pos=0.17}, from=1-1, to=1-2, two heads]
	\arrow[from=2-1, to=1-1]
	\arrow["\circ"{description, pos=0.17}, from=2-1, to=2-2, two heads]
	\arrow[from=2-2, to=1-2]
\end{tikzcd}\]
\end{lemma}

This means that the existence of a p-morphism between two simplicial complexes is preserved under taking subdivisions.

This suggests -but doesn't quite prove- that our notion of p-morphism,
despite depending on the choice of a triangulation is 
actually relative to the underlying polyhedron.

\begin{proposition}
    The realization $|-|$ enjoys the following properties:
    If $U,V\subseteq \Sigma$ are subpolyhedra, then 
    \begin{enumerate}[(i)]
        \item $|U\cup V|=|U|\cup|V|$,
        \item $|U\cap V|=|U|\cap |V|$,
        \item $|\Sigma\setminus U|=|\Sigma|\setminus |U|$.
    \end{enumerate}
\end{proposition}
\begin{proof}
    They follow immediately from the fact that $|U|$ is a disjoint union.
\end{proof}
Moreover we have that the realization of an up-set is open and taking the downward-closure corresponds in the realization to taking the topological closure.
\begin{lemma}[Up-sets are open]
    Let $K=(V,\Sigma)$ be a simplicial complex, $U\subseteq \Sigma$, and consider $|U|=\bigsqcup_{\sigma\in U}\RelInt(\sigma)$.

    Then $|U|$ is open if and only if $U$ is upward-closed. Dually, $|U|$ is closed if and only if $U$ is downward-closed.
\end{lemma}
\begin{proof}
    We may use the characterization that $|U|$ is closed if and only if $|U|\cup\partial |U|=|U|$.

    Note that $\partial |U|$ is given by $|U|\setminus \RelInt(|U|)=|U\setminus U^*|$, where $U^*$ is the set of maximal faces of $U$. This means that $|U|$ is closed if and only if $U$ contains everything below its maximal faces.

    Then $|U|$ is open if and only if $|\Sigma|\setminus|U|=|\Sigma\setminus U|$ is closed, i.e., if and only if $\Sigma\setminus U$ is downward-closed, i.e., if and only if $U$ is upward-closed.
\end{proof}

The topological Goldblatt-Thomason theorem states that a class of topological spaces is modally definable if and only 
if it's closed under disjoint unions, open subsets, image of open continuous maps and Alexandrov extensions.

We expect our result to be similar (save the extensions, parallelly to the finite frame case) to the topological one, thus a closure under 
(finite) disjoint unions, some form of open subsets, and some form of open continuous images.
