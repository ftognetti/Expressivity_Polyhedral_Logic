\section{Definability}
Here we set out the standard versions of our theorem and of our semantics, and explain how we will use them.
\subsection{Polyhedral semantics}
As is always the case, we begin with a language; here, the standard modal language.
\begin{definition}[Modal language]
    Our language is the standard modal language: we assume a (countable) set of propositional variables $X$ and define inductively
    \[\Ll = \set{x\in X \ \|\ \bot\ \|\ \varphi\vee\psi\ \|\ \lnot\varphi\ \|\ \d\varphi}\]
\end{definition}

We interpret our formulas in polyhedra as follows.

\begin{definition}[Polyhedral semantics]
    Let $P$ be a (compact) polyhedron. An \textbf{evaluation} is a map $\nu :\Ll \to \Pp P$ such that $\nu(\varphi)$ is a union of relative interiors of subpolyhedra of $P$.

    We say $P,x\models \varphi$ if and only if $x\in \nu(\varphi)$.

    Moreover, we ask that $\nu$ satisfies the following properties:
    \begin{itemize}
        \item $\nu(\bot)=\emptyset$,
        \item $\nu(\varphi\vee\psi)=\nu(\varphi)\cup\nu(\psi)$,
        \item $\nu(\lnot\varphi)=P\setminus \nu(\varphi)$,
        \item $\nu(\d\varphi)=\overline{\nu(\varphi)}$.
    \end{itemize}

    We say that $\varphi$ \textbf{is valid in} $P$, written $P\models\varphi$, if $P,x\models \varphi$ for every $x\in P$ and every evaluation $\nu$.
\end{definition}

This allows us to define the \textbf{logic} of a polyhedron.
\begin{definition}
    Let $P$ be a polyhedron. We call the \textbf{logic} of $P$ the set
    \[\Log(P):=\set{\varphi\in \Ll:P\models\varphi}\]
\end{definition}

Recall that the Kripke semantics for the modal logic (S4.Grz) interprets the Boolean connectives as usual, together with
\[P,p\models \d\varphi\iff \exists q\geq p: P,q\models\varphi.\]
The following theorem connects the two semantics.
\begin{theorem}
    Let $P$ be a polyhedron and let $K=(V,\Sigma)\in \Tr(P)$ be a simplicial complex realizing $P$.

    For each $x\in P$ there exists a unique $\sigma_x\in \Sigma$ such that $x\in \RelInt(\sigma_x)$, and
    \[P,x\models\varphi \text{ (as polyhedra) if and only if }\Sigma,\sigma_x\models\varphi\text{ (as posets)}.\]
    Moreover,
    \[\Log(P)=\bigcap_{K\in \Tr(P)}\Log([K]).\]
\end{theorem}
\begin{proof}
    See \cite{TENCATE} and \cite{DBLP} for a complete account.
\end{proof}
\subsection{Modally definable classes}

The dual question to validity is definability: given a set of formulas $F$, which class of models satisfies it?

\begin{definition}[MD class]
    Let $F\subseteq \Ll$ be a set of formulas. We call $\Pol(F)$ the class of (compact) polyhedra modeling every formula of $F$, i.e.
    \[\Pol(F)=\set{P\in\Pol: \forall\varphi\in F. P\models\varphi}\]
\end{definition}

We want to establish a Goldblatt-Thomason-like theorem for this class of spaces. Recall the classical result:
\begin{theorem}[Goldblatt-Thomason for finite transitive frames (I)]
    A class of finite transitive models $\C$ is modally definable if and only if it is closed under
    \begin{itemize}
        \item finite disjoint unions,
        \item generated subframes,
        \item p-morphic images.
    \end{itemize}
\end{theorem}
\begin{proof}
    See \cite{Blackburn_Rijke_Venema_2001}, Chapter 3.
\end{proof}
We will see that `generated subframes' correspond to open subpolyhedra. Since our classes are formed of \textbf{compact} polyhedra, open subpolyhedra will never occur among them, so we shall instead use a slightly different but equivalent result:
\begin{corollary}[Goldblatt-Thomason for finite transitive frames (II)]
    A class of finite transitive models $\C$ is modally definable if and only if it is closed under
    \begin{itemize}
        \item finite disjoint unions,
        \item surjective up-reductions,
    \end{itemize}
    where an up-reduction is a partial p-morphism whose domain is a generated subframe.
\end{corollary}
\begin{proof}
    Suppose $\C$ is closed under $(I)$. Let $X\in \C$ and let $f:X\upred Y$ be an up-reduction; call $U$ the domain of $f$, so that $U\in \C$.

    Then $f_{|U}: U\twoheadrightarrow Y$ is a surjective p-morphism, so $Y$ is a p-morphic image of $U$, and thus $Y\in \C$. This means that $\C$ is closed under $(II)$.

    Conversely, suppose that $\C$ is closed under $(II)$. Let $X\in \C$ and let $U$ be a generated subframe of $X$. Then the identity on $U$, seen as a partial map $X\to U$, is an up-reduction. Similarly, if $Y$ is a p-morphic image of $Y$, then, since $X$ is a generated subframe of $X$, we may extract an up-reduction.
\end{proof}

Note that this means the class of models \textbf{is always closed under generated subframes}, but we may intersect this class with a category that lacks them.

We will also make use of the Jankov-Fine axiomatization.

\begin{theorem}[Jankov-Fine]
    Let $U$ be a finite rooted frame. Then there exists a formula $\chi(U)$ such that $F\models\chi(U)$ if $F$ does \textbf{not} up-reduce to $U$.
\end{theorem}
\begin{proof}
    See \cite{Bezhanishvili2022}.%provide a more direct source?
\end{proof}
\begin{corollary}
    A class of finite frames $\C$ in a category of models $\Mod$ can be characterized as
    \[\C=\set{M\in \Mod: \forall U\notin \C \text{ rooted},\  M\models\chi(U)}.\]
\end{corollary}

\subsection{Topological connection}
\begin{proposition}
    The realization $|-|$ enjoys the following properties:
    \begin{enumerate}[(i)]
        \item $|U\cup V|=|U|\cup|V|$,
        \item $|U\cap V|=|U|\cap |V|$,
        \item $|U^\circ|=|U|^\circ$,
        \item $|\Sigma\setminus U|=|\Sigma|\setminus |U|$.
    \end{enumerate}
\end{proposition}
\begin{proof}
    They follow immediately from the fact that $|U|$ is a disjoint union.
\end{proof}

\begin{lemma}[Up-sets are open]
    Let $K=(V,\Sigma)$ be a simplicial complex, $U\subseteq \Sigma$, and consider $|U|=\bigsqcup_{\sigma\in U}\RelInt(\sigma)$.

    Then $|U|$ is open if and only if $U$ is upward-closed.

    Dually, $|U|$ is closed if and only if $U$ is downward-closed.
\end{lemma}
\begin{proof}
    We may use the characterization that $|U|$ is closed if and only if $|U|\cup\partial |U|=|U|$.

    Note that $\partial |U|$ is given by $|U|\setminus \RelInt(|U|)=|U\setminus U^*|$, where $U^*$ is the set of maximal faces of $U$. This means that $|U|$ is closed if and only if $U$ contains everything below its maximal faces.

    Then $|U|$ is open if and only if $|\Sigma|\setminus|U|=|\Sigma\setminus U|$ is closed, i.e., if and only if $\Sigma\setminus U$ is downward-closed, i.e., if and only if $U$ is upward-closed.
\end{proof}
